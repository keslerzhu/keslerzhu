Operational Path LIVE / SERVING

OpenStreetMap and PostgreSQL/PostGIS feed Martin, Nominatim and Valhalla, which serve MapLibre. Separately, IoT events flow through Kafka and the message processor to WebSocket, PostgreSQL and GeoParquet. WebSocket updates MapLibre in real time.

Analytical Path HISTORICAL / LAKEHOUSE

PostgreSQL/PostGIS feeds Spark/Sedona. The analytical pipeline then flows through the Data Lakehouse, MinIO/S3 and GeoParquet. This path is distinct from live map serving.

MCP integration

  • Nominatim and Valhalla provide the tools consumed by the MCP Server.
  • The MCP Server exposes those tools to the AI Agent (VS Code Copilot host).
  • No direct MapLibre-to-MCP, MCP-to-database, or AI-Agent-to-map connection is drawn.
  • All arrows follow the source-to-destination relationships specified for this revision.
