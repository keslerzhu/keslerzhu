Interactive LAYER 1

WebBrowser, MapLibre, AI Agent, MCP Server, IoT and QGIS. People reach the map through the browser; the AI Agent reaches GIS tools through the MCP Server; QGIS works on the spatial database; IoT devices originate the live event stream.

Business logic LAYER 2

Martin, Nominatim, Valhalla and GeoServer serve tiles, geocoding, routing and OGC services. Kafka, the Message Processor and Web Socket carry live events to the map and to storage.

Data lakehouse LAYER 3

Four columns: open source data (OpenStreetMap, osm2pgsql), structured data (PostgreSQL/PostGIS), the analytical engine (Spark/Sedona, Iceberg, GeoParquet) and FS/Object storage (Microsoft Office).

Data governance LAYER 4

OpenMetadata collects metadata from PostgreSQL/PostGIS, Iceberg and Kafka. Apache POI & Tika extract content from Microsoft Office documents and pass it to OpenMetadata.
